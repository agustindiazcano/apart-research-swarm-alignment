# Task List for the Coding Agents

Rules for every task (from `AGENTS.md`, not relaxed): check branch and worktrees first; a separate worktree and branch created from an up-to-date `main` (`feat/<slug>`, `chore/`, `docs/`, `exp/`); failing test first, shown failing for the right reason; implement; lint and tests; atomic commits; update `PENDING.md` and `LASTCONTEXT.md`; ask the human to approve the PR; the PR is based on `main`. Conventional Commits. No em dash and no emojis in documents. Unknown facts stay `TODO(verify)` until verified by running something.

Type checking: `mypy` in standard mode (not `--strict`) to save time; ruff for lint. Tests are written first for every module but kept small, focused on the risky units: action parsing, ground-truth rules, label rules, metrics, detector parsing and thresholds, topology targets, budget guard.

Lanes: A runtime, B measurement, C experiments (see PLAN.md). The critical path is marked (CP).
