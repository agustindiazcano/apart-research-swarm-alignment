The defenses

What is a guardrail?

A guardrail is a filter placed between agents. It reads every message and blocks it before delivery if it looks like an attack.
Ablation ladder: D1 → D2 adds an LLM → D3 adds context → D5 adds tiering. Control: no guardrail. Each gate is calibrated to block at most 0.5% of normal messages.
Result: guardrail by guardrail (ring, split credential)

Every guardrail stopped the spread; they differ in cost

6 episodes per row. The attacker follows a fixed playbook and does not adapt after a block. Exfiltration alone does not separate the gates (see next slide).
