# LaTeX paper

Build: `python scripts/make_paper_assets.py` (figures, tables, `numbers.tex` from `results/campaign/analysis`), then `pdflatex paper.tex` twice in this folder. Copy `paper.pdf` to `report/SWARM_CONTAGION_REPORT.pdf`.

Figures, tables and every number quoted in the prose are generated; do not edit `numbers.tex`, `tables/` or `figures/` by hand.
